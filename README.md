# Практична робота №1 з дисципліни «Об'єктно-орієнтоване програмування»

## Тема

**Класи та об'єкти**

## Опис проєкту

Консольна програма для керування авіарейсами аеропорту.

Основним класом предметної області є `Flight`. Один об'єкт класу `Flight` описує один авіарейс. Програма дозволяє створювати та зберігати об'єкти, переглядати інформацію про рейси, виконувати пошук, демонструвати поведінку об'єктів та видаляти рейси.

Кількість об'єктів обмежується значенням `N`, яке користувач задає під час запуску програми.

## Використані технології

- C#
- .NET
- Console Application
- Visual Studio
- `List<Flight>` для зберігання об'єктів

## Клас `Flight`

Клас `Flight` містить характеристики авіарейсу:

- `FlightNumber` - номер рейсу;
- `Destination` - місто призначення;
- `DepartureTime` - дата та час вильоту;
- `PassengerCount` - кількість пасажирів;
- `TicketPrice` - вартість квитка;
- `Status` - поточний статус рейсу;
- `IsInternational` - ознака міжнародного рейсу.

Для кількості пасажирів і вартості квитка використовуються закриті поля `passengerCount` і `ticketPrice`. Їх значення доступні для читання через властивості `PassengerCount` і `TicketPrice`.

## Перелічуваний тип `FlightStatus`

Статус рейсу задається за допомогою `enum FlightStatus`.

Можливі значення:

- `Scheduled`
- `Boarding`
- `Delayed`
- `Departed`
- `Cancelled`
- `Landed`

`FlightStatus` реалізований в окремому файлі `FlightStatus.cs`.

## Методи класу

Клас `Flight` містить методи, які описують поведінку об'єкта:

- `AddPassenger()` - додає одного пасажира, якщо не досягнуто максимальної кількості 500;
- `DelayFlight(int minutes)` - переносить час вильоту на задану кількість хвилин і встановлює статус `Delayed`;
- `StartBoarding()` - встановлює статус `Boarding`, якщо рейс не скасований, не вилетів і не завершився;
- `CancelFlight()` - встановлює статус `Cancelled`.

## Основне меню програми

Після запуску користувач задає максимальну кількість рейсів `N`, після чого програма працює через консольне меню:

```text
1. Add flight
2. View all flights
3. Find flight
4. Demonstrate behavior
5. Delete flight
0. Exit
```

### 1. Add flight

Користувач вводить усі характеристики нового рейсу. Після перевірки введених даних створюється новий об'єкт `Flight` і додається до колекції `List<Flight>`.

Якщо кількість об'єктів уже дорівнює `N`, додавання нового рейсу блокується.

### 2. View all flights

Програма послідовно проходить по колекції `flights` і виводить детальну інформацію про кожний створений рейс із порядковим номером.

Якщо колекція порожня, виводиться повідомлення `No flights.`.

### 3. Find flight

Пошук реалізований методом лінійного перебору колекції `List<Flight>` за допомогою циклу `foreach`.

Пошук доступний за двома характеристиками:

1. номером рейсу `FlightNumber`;
2. містом призначення `Destination`.

Усі знайдені об'єкти додаються до окремої колекції `foundFlights` і виводяться користувачу.

### 4. Demonstrate behavior

Користувач обирає рейс за його порядковим номером і може викликати один із public-методів класу:

```text
1. Add passenger
2. Delay flight
3. Start boarding
4. Cancel flight
0. Back
```

Зміни виконуються безпосередньо для вибраного об'єкта, який зберігається у колекції `flights`.

### 5. Delete flight

Передбачено два способи видалення:

1. за порядковим номером у списку;
2. за містом призначення `Destination`.

При видаленні за характеристикою видаляються всі рейси, для яких місто призначення співпадає з введеним значенням.

Для безпечного видалення декількох об'єктів цикл проходить колекцію з кінця до початку.

### 0. Exit

Завершує виконання програми.

## Перевірка введених даних

Перед створенням об'єкта програма перевіряє введені користувачем значення.

Основні обмеження:

- `N` має бути додатним цілим числом;
- номер рейсу не може бути порожнім;
- номер рейсу повинен містити від 2 до 7 символів;
- номер рейсу може містити тільки літери та цифри;
- місто призначення не може бути порожнім;
- місто призначення може містити тільки літери та пробіли;
- дата і час вильоту повинні бути в майбутньому;
- кількість пасажирів повинна бути цілим числом від 1 до 500;
- вартість квитка повинна бути більшою за 0 та не перевищувати 10000;
- статус рейсу обирається зі значень `FlightStatus`;
- для міжнародного рейсу користувач вводить `y` або `n`.

## Зберігання об'єктів

Об'єкти зберігаються у колекції:

```csharp
List<Flight> flights = new List<Flight>();
```

Поточна кількість об'єктів визначається через:

```csharp
flights.Count
```

Максимальна кількість рейсів задається користувачем у змінній `maxFlights`.
